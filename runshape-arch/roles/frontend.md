# Frontend

A placeholder lens: not in `taxonomy.ts` yet, so Runshape won't tag these. A map may use them.

### `component`
A piece of UI: props in, events out.

### `store`
State shared across components.

### `hook`
Reusable stateful logic for components.

### `design-system-component`
A generic component with no knowledge of the product, shared between apps.
Look-alike: `component` knows about the product's domain.
