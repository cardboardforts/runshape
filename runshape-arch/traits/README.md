# Traits

What code does when it runs. Each axis is independent. Unlike roles, traits are mostly detected from
a recording rather than assigned in an interview, because a person's memory of them is worse than
the trace. Ids match `packages/architecture/src/taxonomy.ts`.

| File | Covers |
|---|---|
| [callables.md](callables.md) | Effect, I/O, CQS, failure, intent |
| [state.md](state.md) | Mutability, scope, role. Not in `taxonomy.ts` yet |
| [metadata.md](metadata.md) | What decorators and annotations are evidence of |
